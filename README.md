# Student Marks Prediction Using Machine Learning

## Project Overview

Student Marks Prediction is a beginner-friendly Machine Learning project that predicts a student's expected marks based on the number of hours they study.

The project uses **Python and Linear Regression** to identify the relationship between study time and academic performance. It demonstrates how machine learning can be used to analyse data and make predictions.

## Key Features

- **Data Analysis:** Analyse student study hours and marks using Python.
- **Data Preprocessing:** Identify and handle missing values to improve data quality.
- **Data Visualization:** Display the relationship between study hours and marks using Matplotlib.
- **Model Development:** Train a Linear Regression model using Scikit-learn.
- **Performance Evaluation:** Evaluate the model using the R-squared score.
- **Marks Prediction:** Estimate student marks based on study hours.
- **Model Saving:** Save the trained model using Joblib for future use.

## Technologies Used

- Python
- Pandas

- Matplotlib
- Scikit-learn

## Project Workflow

1. Collect student study-hour and marks data.
2. Load the dataset using Pandas.
3. Clean and preprocess the data.
4. Perform exploratory data analysis.
5. Visualize the data using Matplotlib.
6. Train the Linear Regression model.
7. Evaluate model performance.
8. Predict student marks using study hours.
9. Save the trained model for future use.

**Step 1: Clone the repository**

```bash
git clone https://github.com/rohit-123ade/Student-Marks-Prediction-using-ML.git
```

**Step 2: Open the project folder**

```bash
cd Student-Marks-Prediction-using-ML
```

**Step 3: Install the required libraries**


**Step 4: Launch Jupyter Notebook**

